# TICHU — A CARD GAME GUIDE

> **VS Code에서 이어서 작업하기:** [HANDOFF.md](./HANDOFF.md)에 현재 구현, 파일별 변경, 검증 기록, 남은 문제와 다음 작업을 정리했습니다.

모바일 우선으로 만든 한국어 티츄 디지털 설명서입니다. Next.js App Router, TypeScript, Tailwind CSS 4, Motion, Lucide React, Pretendard를 사용합니다.

## 실행

Node.js 20.9 이상에서 실행하세요.

```sh
npm install
npm run dev
```

http://localhost:3000 에서 확인할 수 있습니다.

```sh
npm run build
npm run typecheck
npm start
```

환경변수 없이 FAQ 검색이 동작합니다. `.env.example`은 향후 서버 AI 연결을 위한 안내입니다. 현재 생성형 AI는 연결하지 않았고 화면에 **규칙 검색 모드**로 표시합니다.

## 구현된 기능

- 4·5·6인 전역 상태, 로컬 저장 및 새로고침 복원
- 축소 헤더, 모바일 전체 메뉴, 챕터 이동, 5분 가이드
- 기본 규칙, 8종 카드 조합 비교, 특수 카드, 인원별 선언·점수·순위
- 56장 도감, 6종 필터, 확대, 이전·다음, 모바일 좌우 스와이프
- 인원에 맞는 용어집·통합 검색·Quick Guide
- 임시 픽셀 캐릭터 4종과 걷기·대기·점프·대화 표현
- NPC 질문 패널 및 서버 FAQ 검색 `/api/chat`
- 모달 Escape 닫기, 초점 순환·복원, 키보드 조작, 모션 감소

## 파일 구성

- `src/components/GuideApp.tsx`: 페이지 구성, 공유 인원 상태, 패널 제어
- `src/components/Rules.tsx`: 설명 펼치기와 카드 조합 비교
- `src/components/CardGallery.tsx`, `PlayingCard.tsx`: 카드 도감과 상세 UI
- `src/components/NPC.tsx`, `PixelCharacter.tsx`: 캐릭터·질문 UI
- `src/components/Modal.tsx`: 재사용 가능한 접근성 모달
- `src/data/cards.ts`: 일반 카드 52장 + 특수 카드 4장
- `src/data/images.ts`: 카드 사진과 캐릭터 파일 매핑
- `src/data/rules.ts`: 인원·검색어·예시·주의사항을 가진 규칙 데이터
- `src/lib/search.ts`: 클라이언트와 서버에서 공유하는 검색
- `src/app/api/chat/route.ts`: 입력 검증 및 FAQ 응답

## 실제 이미지 적용

카드 56장은 이미 `public/cards/`에 연결되어 있습니다. 무늬는 칼·초승달·별·집이며, `src/data/images.ts`가 카드 ID와 PNG 경로를 매핑합니다. 숫자 카드는 원본 무늬를 재배치했고, 인물·A·특수 카드는 제공된 그림을 사용했습니다.

카드 ID는 `s1-2` … `s4-A`, `dragon`, `dog`, `phoenix`, `sparrow`입니다. 로딩에 실패하면 기존 플레이스홀더를 표시합니다. 재생성 방법과 원본 해상도 한계는 [HANDOFF.md](./HANDOFF.md)를 확인하세요. 픽셀 NPC 디자인은 그대로 유지합니다.

## 규칙의 기준과 미확정 항목

사용자 제공 요청서와 Fata Morgana 공개 영문 규칙을 참고했습니다.
https://fatamorgana.ch/fatamorgana/tichu/english-rules

**5인 안내는 제공된 한국어 설명서 ‘쟁상유’ 16–18쪽을 반영했습니다.** 분배·첫 판·세금·자리·종료를 사이트 안에서 확인할 수 있습니다. 6인 분배 등은 기존 공개 영문 규칙 안내와 구분합니다. 도감은 전체 56장을 보여주며 개에는 5인 사용 제외를 표시합니다.

API는 외부 모델에 질문을 보내지 않습니다. 규칙 데이터를 교체하면 모든 검색 화면에 반영됩니다. 미래에 AI를 연결할 경우 키는 서버 환경변수에만 저장하고, 선택한 인원의 검증된 규칙만 서버에서 검색해 제공하세요. `NEXT_PUBLIC_`에 비밀 키를 넣지 마세요.

Pretendard는 jsDelivr에서 불러옵니다. 인터넷이 없는 환경에서는 시스템 글꼴로 대체됩니다. 완전한 오프라인 배포가 필요하면 폰트를 로컬로 저장해 CSS의 폰트 선언을 교체하세요.

## 한국어 쟁상유 5인 규칙 반영

근거: 사용자가 제공한 한국어 종이설명서 사진 16–18쪽. 사진을 웹에 공개하지 않고 필요한 규칙을 정리했습니다.

- 개 제외 55장, 5명에게 11장씩 균등 분배.
- 첫 판은 카드 교환·세금 없이 참새 보유자가 시작.
- 둘째 판부터 최하위→최상위 2장, 아래에서 둘째→위에서 둘째 1장, 가운데 0장. 받는 사람은 원래 손패에서 원하는 같은 장수를 선택하여 동시에 하사.
- 세금 선택 순서: 용 > 봉황 > 참새 > A > K > Q > J > 10 > … > 2. 일반 플레이의 강함과 별도 표시.
- 한 사람만 패가 남으면 라운드 종료, 손을 비운 순위로 새 신분·좌석 결정. 딴 트릭 점수와 팀전 선언을 사용하지 않으며 고정 목표 점수 없음.
- 설명서의 여섯 자리 예시 중 ‘상인’을 생략해 5인 표기를 황제·재상·장군·평민·천민으로 통일. 이는 순위를 보여주기 위한 사이트 표기 선택임을 본문에도 명시.
- `src/data/fivePlayer.ts`가 5인 원본 데이터와 일반 규칙의 5인 설명을 관리. 단계·본문·검색·NPC·카드 상세에 공유.
- 새 방문 기본값은 5인. 기존 사용자의 저장된 인원 선택은 유지.

검증: 프로덕션 빌드·타입 검사 통과. `node scripts/check-five-rules.cjs`로 5인 미확인 문구 부재·세금 순서·질문 검색·4/6인 분리 검증. 실제 API 8개 질문 통과. 브라우저에서 분배와 교환 단계, 네 학습 탭, NPC 세금 답변 확인. 360·390px 가로 넘침 없음.


## 실물 카드 시트 반영

일반 카드 52장과 특수 카드 4장, 총 56장을 `public/cards/`에 연결했습니다. sword·crescent·star·house 폴더는 2–A, special 폴더는 mahjong·dragon·dog·phoenix입니다. 뒷면은 제외했습니다.

숫자 카드 36장은 원본 무늬를 추출하여 숫자와 동일한 개수로 재배치했습니다. J·Q·K·A와 특수 카드는 제공된 시트의 그림을 사용합니다. 출력은 224×384 PNG이며, 원본 해상도로 인해 확대 시 얼굴 그림의 선명도에는 한계가 있습니다.

`scripts/extract-cards.py`로 재생성할 수 있습니다(Pillow 필요, 다른 운영체제는 CARD_FONT로 글꼴 경로 지정). 추출 좌표와 무늬 개수는 `public/cards/manifest.json`에 기록했습니다.

PlayingCard·CardGallery 및 카드 이미지 매핑과 스타일을 변경했습니다. 규칙·점수·NPC 로직은 유지했습니다. 빌드와 타입 검사 통과, 브라우저 56장 이미지 로딩·무늬/숫자 필터·특수 4장·카드 상세 확인 완료.
